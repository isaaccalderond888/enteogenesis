# Enteogénesis · Terrasana

Micrositio de admisión para el retiro Enteogénesis.
Quien aplica llena la ficha aquí; Isaac y Claudia la leen en el archivo interno.

- Público: `/` (ficha) · `/gracias`
- Interno: `/adminlogin` → `/expedientes`
- Sitio madre: [terrasana.pro](https://terrasana.pro/)

## Enlace para aplicar

Cuando Vercel termine el primer deploy, el enlace público será algo como:

`https://enteogenesis.vercel.app`

Ese es el que se pega en Terrasana o se comparte directo. No hace falta menú extra.

## Archivo interno

1. Entra a `/adminlogin`
2. La primera cuenta que entra queda como staff
3. Desde ahí se invita a Claudia

## Dominio

Cuando lo tengas: Vercel → Project → Settings → Domains.
